# Scientific Assistant

## Objetivo

Implementar únicamente esta fase.

## Trabajo

- Query layer sobre datos.
- Tool-based responses.
- Citations to runs/frames.
- Charts/tables.
- Refusal to invent missing evidence.

## Criterios de aceptación

- [ ] Toda respuesta puede abrir evidencia.
- [ ] No responde con valores ausentes.
- [ ] Distingue observed vs inferred.

## Entregable obligatorio

Crear `PHASE_RESULT.md` con:

```text
status
implemented
files_changed
tests
metrics
known_issues
next_phase_blockers
```
