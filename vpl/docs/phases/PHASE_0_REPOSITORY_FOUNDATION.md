# Repository Foundation

## Objetivo

Implementar únicamente esta fase.

## Trabajo

- Inicializar monorepo.
- Configurar Tauri + React + TypeScript.
- Crear Python workspace.
- Configurar lint, format, tests y pre-commit.
- Crear schemas base.
- Crear logging estructurado.
- Crear Run_ID y provenance mínimos.

## Criterios de aceptación

- [ ] App abre.
- [ ] Tests base pasan.
- [ ] Python y TS se comunican mediante un health check.
- [ ] Existe estructura de carpetas acordada.
- [ ] No existe lógica Powerball en core.

## Entregable obligatorio

Crear `PHASE_RESULT.md` con:

```text
status
implemented
files_changed
tests
metrics
known_issues
next_phase_blockers
```
