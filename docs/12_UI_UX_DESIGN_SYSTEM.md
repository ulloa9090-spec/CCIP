# 12 — UI/UX Design System

## Character
Fast professional measuring instrument, not a dense WMS.

## Inspiration principles only
- Apple Camera: camera-first simplicity.
- Google Maps: spatial fluidity and bottom sheets.
- Linear: speed/hierarchy.
- GitHub: structured records/history.
- Notion: flexible readable records.

Do not copy proprietary layouts, assets or branding.

## Navigation
`Measure | Spaces | Storage | Records | More`

Storage contains both Spots and Bins.

## Capture selector
At measurement start provide a compact context selector:
`Object | Spot | Bin`

Labels/help clarify:
- Object = item/package
- Spot = storage location
- Bin = physical container

## Visual language
- neutral foundation
- one accent
- light/dark modes
- measurements strongest typographic hierarchy
- status not color-only
- large touch targets
- contextual controls
- short purposeful motion

## Operator mode
One-handed, minimal typing, voice-note shortcut, strong contrast, clear success/failure.

## Trust
Distinct presentation for:
- measured
- estimated
- manually edited
- low confidence
