# 15 — Exports & Integrations

## Exports
- PDF report
- CSV
- JSON
- image summary
- OS share sheet

## Record report
Selectable fields, photos, dimensions, weight, quality, placement and provenance.

## Sharing
Use native share mechanisms so compatible installed apps (mail, messaging, etc.) can receive exported files.

## Future
- WMS/ERP APIs
- carrier/shipping systems
- barcode/QR
- RFID
- webhooks
- enterprise identity
- cloud AI for optional non-geometric tasks

## Rule
External services are adapters/integrations, not dependencies of core measurement.
