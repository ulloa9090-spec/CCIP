# 08 — Digital Records

## Record
A durable digital file for a measured/inspected Object, Bin or Spot.

## Contents
- ID/type
- L/W/H
- volume
- measurement method
- confidence/uncertainty
- actual weight where relevant
- optional dimensional weight
- photos
- written notes
- voice/transcription
- tags/custom identifiers
- current placement
- timestamps
- operator/device
- calibration/provenance

## Audit
Manual edits retain original machine measurement, edited value, user/reason and timestamp.

## Actions
- re-measure
- assign/move
- share
- PDF
- data export
- duplicate where appropriate

PDF is presentation output, not canonical storage.
