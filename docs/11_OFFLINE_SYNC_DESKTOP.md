# 11 — Offline, Sync & Desktop

## Offline-first
Without internet the phone must support:
- measurement;
- Spot/Bin/Object creation;
- records/photos/notes;
- locally cached compatibility;
- assignment;
- queued changes.

## Sync options
1. Account/cloud sync.
2. Trusted local-network sync.
3. File archive/import/export.

USB may be evaluated later but is not the primary dependency.

## Desktop
- search/filter records
- manage Spots/Bins
- bulk operations
- reports
- device/station management
- sync/conflicts
- analytics

## Conflict model
Stable IDs + revisions/timestamps + explicit resolution for conflicting user edits.

## Security
Encrypted transport, protected credentials, explicit device pairing and least-privilege access.
