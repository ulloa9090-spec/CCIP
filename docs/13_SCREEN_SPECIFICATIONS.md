# 13 — Screen Specifications

## 1. Measure
Full-screen camera.
Top/compact selector: `Object | Spot | Bin`.
Overlay: target outline, 3D box, L/W/H and quality.
Bottom sheet: volume, weight, photos, notes, save.

## 2. Selective Space Mapper
`New Space | Open Space`.
Guide only the user-selected bounded area.
Show floor/boundary/anchors and calibration state.

## 3. Storage
Segmented control:
`Spots | Bins`

### Spots
Show rack/opening/slot imagery or simple location diagram, code, usable dimensions and status.

### Bins
Show physical container/tote imagery, code, internal dimensions and current Spot if assigned.

## 4. Add Spot
`Measure with Camera | Enter Dimensions | Create from Space`
Save rack/zone/location metadata.

## 5. Add Bin
`Measure with Camera | Enter Dimensions`
Capture internal dimensions; optionally external dimensions.

## 6. Compatibility
Select comparison:
- Object → Spot
- Object → Bin
- Bin → Spot

Show best fit, orientation, clearance, alternatives and rejection reasons.

## 7. Digital Record
ID/type, dimensions, volume, weight, quality, photos, notes, placement and history.
Actions: Assign/Move, Share, PDF, Export, Re-measure.

## 8. Placement
Examples:
`Place Object in Spot`
`Place Object in Bin`
`Place Bin in Spot`

If Object is in Bin and Bin moves Spots, preserve hierarchy/history.

## 9. Records
Search/filter by type, code, date, Spot, Bin, tags and quality.

## 10. Hardware/Station
Connected devices, calibration and diagnostics. Normal users see simple states, not raw sensor streams.

## 11. Settings
- Language
- Units
- Appearance
- Measurement preferences
- Sync
- Privacy
- Device capabilities
